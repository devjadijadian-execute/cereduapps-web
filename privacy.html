Kebijakan Privasi

Ceredu Apps

Privasi Anda adalah prioritas kami — data Anda, kendali Anda

1. Pendahuluan

Kebijakan Privasi ini menjelaskan bagaimana Ceredu Apps ("kami", "Aplikasi") mengumpulkan, menggunakan, dan melindungi informasi Anda saat menggunakan aplikasi kami. Kami berkomitmen untuk transparan mengenai praktik data dan menghormati privasi Anda, terutama karena Aplikasi ini dirancang untuk mendukung produktivitas bisnis Anda sehari-hari.

2. Prinsip Privasi Kami

Ceredu Apps dibangun dengan prinsip privacy-first:

  • Data pertama-tama disimpan di perangkat Anda (offline-first).
  • Kami tidak meminta izin yang tidak diperlukan untuk fungsi inti Aplikasi.
  • Kami tidak pernah meminta izin lokasi.
  • Kami tidak pernah meminta izin baca/tulis penyimpanan eksternal secara langsung — Aplikasi menggunakan Storage Access Framework (SAF) dan MediaStore Android yang lebih aman.
  • Barcode scanning menggunakan ML Kit on-device processing — tidak ada data kamera atau barcode yang dikirim ke server eksternal.

3. Informasi yang Dikumpulkan

3.1 Data yang Disimpan Lokal di Perangkat Anda

Data berikut disimpan sepenuhnya di perangkat Anda menggunakan database lokal (Room) dan tidak dikirimkan ke server manapun tanpa izin eksplisit Anda:

  • Data resi: nomor resi, status pengiriman, nama kurir, dan informasi sesi serah terima.
  • Data sesi handover: informasi sesi serah terima ke kurir, termasuk tanda tangan digital (jika digunakan) dan jejak audit aktivitas.
  • Template label dan template cetak kustom yang Anda buat.
  • Ukuran kertas kustom yang Anda simpan.
  • Profil toko yang Anda atur.
  • Riwayat dokumen dan file yang pernah Anda buka melalui Aplikasi (URI-based, bukan salin file).

3.2 Izin Aplikasi dan Tujuannya

Aplikasi meminta izin berikut dengan tujuan yang spesifik:

  • Bluetooth (BLUETOOTH_CONNECT/SCAN, tanpa akses lokasi): digunakan semata-mata untuk mendeteksi dan terhubung ke printer thermal Bluetooth. Kami menggunakan flag neverForLocation untuk memastikan Bluetooth tidak dipakai untuk pelacakan lokasi.
  • Internet: digunakan untuk koneksi cetak WiFi/IPP ke printer jaringan lokal, serta untuk memuat iklan AdMob (varian free) dan integrasi Firebase di masa mendatang (Fase 2).
  • ACCESS_NETWORK_STATE & ACCESS_WIFI_STATE: digunakan untuk memeriksa status koneksi WiFi sebelum mengirim pekerjaan cetak.
  • CHANGE_WIFI_MULTICAST_STATE: digunakan untuk penemuan printer otomatis melalui mDNS (Multicast DNS) di jaringan lokal.
  • Kamera (CAMERA): digunakan untuk memindai barcode nomor resi menggunakan ML Kit. Pemrosesan dilakukan sepenuhnya di perangkat — tidak ada gambar atau data kamera yang dikirimkan ke server eksternal.
  • Notifikasi (POST_NOTIFICATIONS, Android 13+): digunakan untuk menampilkan notifikasi status pekerjaan cetak.

3.3 Data yang Dikumpulkan oleh Pihak Ketiga

Komponen pihak ketiga berikut mungkin mengumpulkan data sesuai kebijakan privasi masing-masing:

  • Google AdMob (varian free): menampilkan iklan banner dan dapat mengumpulkan data untuk keperluan penargetan iklan sesuai Kebijakan Privasi Google. Anda dapat mengelola preferensi iklan melalui pengaturan perangkat Android Anda.
  • Google Firebase (direncanakan di Fase 2): setelah diaktifkan, Firebase Crashlytics dapat mengumpulkan laporan crash anonim, dan Firebase Analytics dapat mengumpulkan data penggunaan anonim untuk membantu kami meningkatkan Aplikasi. Implementasi ini direncanakan bersifat opt-in dan menghormati privasi pengguna.
  • Google ML Kit (Barcode Scanning): pemrosesan barcode dilakukan sepenuhnya on-device. Google ML Kit tidak mengirimkan data gambar atau barcode ke server Google.

4. Cara Kami Menggunakan Informasi

Data yang tersimpan di perangkat Anda digunakan semata-mata untuk:

  • Menjalankan fitur inti Aplikasi: manajemen resi, pencetakan, dan pengelolaan sesi handover.
  • Menyimpan preferensi dan konfigurasi Anda (template, ukuran kertas, profil toko).
  • Menghasilkan dokumen PDF berita acara handover sesuai permintaan Anda.

Kami tidak menggunakan data Anda untuk:

  • Profiling atau analisis perilaku pengguna yang bersifat invasif.
  • Penjualan data kepada pihak ketiga.
  • Penargetan iklan berbasis konten resi atau aktivitas bisnis Anda.

5. Penyimpanan dan Keamanan Data

Semua data operasional Anda (resi, sesi, template) disimpan secara lokal di perangkat Anda menggunakan Room Database (SQLite). Data ini hanya dapat diakses oleh Aplikasi Ceredu Apps dan tidak dapat diakses oleh aplikasi lain.

Untuk keamanan sesi handover, Aplikasi menyediakan fitur PIN lock yang menggunakan hash SHA-256 — PIN Anda tidak disimpan dalam bentuk teks biasa. Tanda tangan digital untuk serah terima resi disimpan sebagai file gambar di direktori cache aplikasi.

Penting: Kami saat ini belum mengimplementasikan sinkronisasi cloud. Jika Anda menghapus Aplikasi atau melakukan factory reset, data lokal Anda akan terhapus. Kami menyarankan Anda untuk melakukan ekspor PDF/CSV secara berkala sebagai cadangan.

6. Berbagi Data dengan Pihak Ketiga

Kami tidak menjual, menyewakan, atau menukar informasi pribadi Anda dengan pihak ketiga manapun. Satu-satunya berbagi data yang terjadi adalah:

  • Dengan Google AdMob, untuk keperluan penyajian iklan pada varian free, sesuai kebijakan Google.
  • Dengan printer yang Anda pilih, di mana Aplikasi mengirimkan data dokumen/resi yang Anda minta untuk dicetak melalui jaringan lokal (WiFi/Bluetooth). Data ini tidak meninggalkan jaringan lokal Anda.

7. Hak-Hak Anda

Karena data Anda disimpan secara lokal, Anda memiliki kendali penuh atas data tersebut:

  • Hak Akses: Anda dapat mengekspor seluruh data resi dan sesi handover dalam format PDF atau CSV kapan saja, tanpa batasan.
  • Hak Hapus: Anda dapat menghapus resi, sesi, template, atau profil toko langsung dari dalam Aplikasi. Menghapus Aplikasi dari perangkat akan menghapus semua data lokal.
  • Hak Portabilitas: Ekspor PDF/CSV tersedia tanpa watermark dan tanpa kuota sebagai bagian dari komitmen fitur gratis kami.

8. Privasi Anak-Anak

Ceredu Apps tidak dirancang untuk atau ditujukan kepada anak-anak di bawah 13 tahun. Kami tidak dengan sengaja mengumpulkan informasi pribadi dari anak-anak di bawah 13 tahun.

9. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu, terutama seiring dengan penambahan fitur baru (seperti integrasi Firebase di Fase 2). Perubahan signifikan akan diinformasikan melalui pembaruan Aplikasi di Google Play Store. Kami mendorong Anda untuk meninjau kebijakan ini secara berkala.

10. Kontak

Jika Anda memiliki pertanyaan, kekhawatiran, atau permintaan terkait Kebijakan Privasi ini atau penanganan data Anda, silakan hubungi kami melalui halaman Google Play Store Ceredu Apps atau melalui saluran komunikasi yang tercantum di profil pengembang.
